## Sobre o projeto

Site estático desenvolvido como atividade acadêmica da **UNINTER**, com uma apresentação pessoal distribuída em seções. O objetivo foi exercitar **HTML semântico, navegação por âncoras e estilização em CSS**, organizando informações de um portfólio simples.

## Conteúdo

- **Sobre mim:** apresentação pessoal e fotografia.
- **Formação:** seção dedicada ao percurso educacional.
- **Portfólio:** acesso ao perfil do GitHub.
- **Contato:** formulário visual com campos de nome, e-mail e mensagem.

> Este repositório é um **registro do momento em que o exercício foi feito**. Os dados de formação e idade presentes no site não representam necessariamente o perfil atual. O formulário é apenas ilustrativo: não há serviço configurado para receber mensagens.

## Tecnologias

**HTML · CSS** — sem frameworks, backend ou etapa de build.

## Executar localmente

1. Baixe ou clone o repositório.
2. Abra `index.html` no navegador.
3. Use o menu superior para navegar entre as seções.

## Estrutura

~~~text
index.html   estrutura do portfólio e suas seções
estilo.css   aparência visual da página
assets/      imagens utilizadas no projeto
~~~
